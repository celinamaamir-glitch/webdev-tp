1. Précurseurs et idées fondatrices

Vannevar Bush (1945) — Le Memex

En 1945, Vannevar Bush propose le concept du Memex, un système permettant d'organiser et de consulter des documents grâce à des associations d'idées.

Ted Nelson (1965) — L'hypertexte

Ted Nelson popularise le terme hypertexte en 1965. L'hypertexte permet de relier différents documents grâce à des liens.

2. Naissance du Web — Tim Berners-Lee et premières implémentations

1989-1991 — Tim Berners-Lee au CERN : HTML, HTTP, URL

En 1989, Tim Berners-Lee propose un système de partage d'informations au CERN. Ce projet donnera naissance au World Wide Web.

Le Web repose sur trois technologies fondamentales :

  • HTML : langage permettant de structurer les pages Web.
  • HTTP : protocole permettant la communication entre navigateur et serveur.
  • URL : adresse permettant d'identifier une ressource sur le Web.

1993-1994 — Premiers navigateurs graphiques : Mosaic et Netscape

Le navigateur Mosaic contribue à populariser le Web grâce à son interface graphique. Netscape participe ensuite à la diffusion du Web auprès du grand public.

1994-1996 — Standardisation et premiers moteurs de recherche

En 1994, le W3C est créé pour accompagner la standardisation des technologies du Web. Les premiers moteurs de recherche facilitent l'accès aux informations disponibles sur Internet.

3. Le Web sémantique, Linked Data et Solid

Le Web sémantique : objectifs et composants

Le Web sémantique vise à rendre les informations du Web compréhensibles et exploitables par les machines. Il permet de relier les données et de faciliter leur traitement.

  • RDF : modèle de représentation des données.
  • OWL : langage permettant de décrire des ontologies.
  • SPARQL : langage permettant d'interroger des données RDF.
  • Ontologies : modèles permettant de décrire des concepts et leurs relations.

Linked Data

Linked Data permet de publier et de connecter des données sur le Web. Les données sont reliées entre elles afin de faciliter leur découverte et leur utilisation.

Solid (Social Linked Data)

Solid est un projet visant à donner aux utilisateurs davantage de contrôle sur leurs données personnelles. Les données peuvent être stockées dans des espaces personnels appelés Pods.

Le projet Solid repose notamment sur les principes suivants :

  • Contrôle des données personnelles.
  • Stockage décentralisé.
  • Partage des données avec autorisation.

Critiques et limites du Web sémantique

Le Web sémantique présente plusieurs difficultés, notamment la complexité de certaines technologies et leur adoption.
